# EconomizaJá Santos

Protótipo Integrador - Comparador de Preços de Supermercado em Santos, SP.

Projeto Integrador em Computação II - UNIVESP.

## Sobre

Aplicação web de arquivo único (`index.html`) que permite montar uma lista de compras e descobrir a melhor opção de compra entre 3 supermercados da cidade de Santos, SP:

- Atacadão Santos
- Pão de Açúcar - Gonzaga
- Carrefour - Ponta da Praia

### Funcionalidades

- Busca inteligente com autocompletar em catálogo de 150 produtos (5 categorias).
- Criação de lista de compras com controle de quantidade.
- Motor de cálculo com 2 estratégias:
  - **Melhor Loja Única**: menor valor total comprando tudo em um único mercado.
  - **Economia Máxima Multi-Lojas**: divisão da compra levando cada produto onde está mais barato.
- Comparativo geral de valores entre os 3 mercados.
- Modo Checklist Presencial com checkboxes para marcação durante a compra.

> Os dados de preços são **fictícios**, simulando a concorrência entre as lojas para fins de demonstração. Última coleta simulada: 01/08/2026.

## Como executar

Como é um protótipo de arquivo único estático, basta abrir o `index.html` em qualquer navegador ou publicar em qualquer hospedagem estática (como o GitHub Pages).
